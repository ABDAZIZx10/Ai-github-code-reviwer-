# Experiments

## `gemini_unofficial.py`

Unofficial Gemini web-UI scraper used during exploration. It is **not** a supported Google AI API client, requires a browser session cookie, and is **not confirmed** as the LLM used in the original n8n production path.

Do not use this in CI or production. Prefer an official provider credential inside n8n (Google AI / OpenAI / Anthropic / etc.).
